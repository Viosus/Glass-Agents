## Windows 限制（这些包未装，需要时走替代方案）
- **vLLM** — 不支持原生 Windows → WSL2 或 transformers 推理。
- **flash-attn** — 难编译 → PyTorch 内置 SDPA。
- **DeepSpeed** — 支持差 → 单卡用 accelerate + bitsandbytes。
- **triton** — 无官方 Windows wheel → 需 `torch.compile` 时装 `triton-windows`。
- **xformers** — 暂无匹配 torch 2.11 的 wheel。

## GlassApp 打分算法三副本（2026-07-12 确认，改算法必读）
同一套六指标打分算法存在**三份等价实现**，改任何一处算法/参数必须三处同步（无自动漂移检测）：
- **Python 权威版**：`D:\GlassApp\fringe_scoring\`——全功能（整床切片/透视矫正/厚度档/多方案），桌面+服务器共用；参数=`D:\GlassApp\config\app_config.yaml`。
- **Dart 版**：`D:\GlassApp\mobile_app\lib\fringe\{fringe_algo,local_config,local_runner}.dart`——Android/iOS App「本地估算」模式（iOS 无独立实现，纯 Flutter 共享）；从 JS 版 1:1 移植。
- **JS 版**：`D:\明之言小程序\workers\scoring\algo.js` + `utils\{local_algo,local_config}.js`——微信小程序「本地估算」；从 Python 逐位移植（相对偏差 ≤7e-12）。已入 git：GitHub private `Viosus/mingzhiyan-weapp`（真实 appid 工作副本，仓库须保持 private）。
- 移动端「简化」≠算法不同：算法本体逐位对齐，差异仅处理分辨率长边≤2000px、参数为 **local_config 手工快照**（改 app_config.yaml 后须手工同步两份 local_config，文件头有同注释）。
- 移动端另有**整床多片检测前置段**（2026-07-13 由单片扩展）：`sheet_detect.dart` / `workers/scoring/sheet_detect.js`——裁边→暗背景阈值→闭运算→8 连通全部连通域（RETR_EXTERNAL 语义，嵌套域剔除）→逐域过滤（围合面积/最短边/填充率）→逐域 4 角拟合+遮挡边补全→阅读序→逐片透视矫正喂 analyzeGray。对应 Python `sheets.detect_sheet_quads_with_meta`；**轮廓跟踪/凸包序/approxPolyDP 为 cv2 精确移植**（与真 cv2 4.13 逐序列 fuzz 全等；5 张真实整床照 25 片角点 0px、总分 Δ≤0.12）。移动端专属差异：`full_frame_frac`/`min_fill_frac` 两道护栏 + 检测异常一律退整图口径（Python 抛错拒绝）。⚠️ 凡 Python `round()` 处移植必须用**半到偶舍入**（JS `Math.round`/Dart `.round()` 半向上会差 1px 致矫正网格错位）。改检测几何须两移动端同步（Python 是权威不动）；local_config 快照含 sheets 段 4 参数（edge_trim/close/min_side/max_sheets）。
- 对齐工具：Dart `mobile_app\tool\{verify_algo,verify_detect}.dart`；JS 的 algo.js / sheet_detect.js 可 node 直跑对拍（sheet_detect.js 另导出 `_geom` 测试钩子）。
- 三端 UI（桌面 analysis_page / Flutter result_page.dart / weapp pages/result）都直接消费结果里的 `verdict` 字段，判定=total < fail_line（+复核门覆盖）。

## Claude Code 工程约定
- **skill 自动发现**：`.claude/skills/<name>/SKILL.md`；模板 / 索引文件**别命名为 SKILL.md**、别放进子目录，否则被误当 skill 加载。
- **hook**：由 `.claude/settings.json` 用 **venv python** 启动；路径含空格（"Glass Agents"）需引号；`chmod` 在 Windows 跳过。hook 内 `subprocess` 用 `sys.executable` 跑 pytest。
- **VS Code 扩展**：面板对自定义 **subagent** 曾有不识别问题，但 **hook / skill 不受影响**；用 `/hooks` 复核注册。
- **config 调用方式**：config 不是后台常驻，而是被 `tools/` 函数在**每次调用时**从磁盘读 —— 改 yaml 即时生效，无需重启或改代码。
