## 训练环境（2026-06-22 配置完成）
- **GPU**：NVIDIA RTX 5070, 12GB（Blackwell, sm_120），驱动 610.62，支持 CUDA 12.8。
- **venv**：`D:\Glass Agents\.venv`（Python 3.12.10）；激活 `D:\Glass Agents\.venv\Scripts\Activate.ps1`。
- **解释器陷阱**：系统 `python`=3.14（无 ML wheel）、`python3`=Microsoft Store 假桩。**一律用 venv python**：`D:\Glass Agents\.venv\Scripts\python.exe`（`py -3.12` 也可调 3.12）。
- **PyTorch**：2.11.0+cu128（Blackwell **必须 cu128**），从 `https://download.pytorch.org/whl/cu128` 安装。
- **已装核心包**：
  - LLM：transformers, datasets, accelerate, peft, trl, bitsandbytes(4bit 可用), sentencepiece, safetensors, tokenizers, evaluate, einops, huggingface_hub
  - CV：timm, opencv-python, albumentations, scikit-image, ultralytics, pycocotools
  - 通用：numpy, pandas, scipy, scikit-learn, matplotlib, seaborn, jupyterlab, tensorboard, wandb
  - 测试/护栏：pytest, pyyaml
  - 清单见 `requirements.txt`（torch 系单独从 cu128 源装，不在该文件内）。
- **诊断脚本**：`check_gpu.py`（验证 CUDA）、`check_env.py`（验证所有包 import）。
- **12GB 显存**：LLM 微调走 **QLoRA**（peft + bitsandbytes 4bit），7B 模型可在 12GB 内训练。

## Windows 限制（这些包未装，需要时走替代方案）
- **vLLM** — 不支持原生 Windows → WSL2 或 transformers 推理。
- **flash-attn** — 难编译 → PyTorch 内置 SDPA。
- **DeepSpeed** — 支持差 → 单卡用 accelerate + bitsandbytes。
- **triton** — 无官方 Windows wheel → 需 `torch.compile` 时装 `triton-windows`。
- **xformers** — 暂无匹配 torch 2.11 的 wheel。

## Claude Code 工程约定
- **skill 自动发现**：`.claude/skills/<name>/SKILL.md`；模板 / 索引文件**别命名为 SKILL.md**、别放进子目录，否则被误当 skill 加载。
- **hook**：由 `.claude/settings.json` 用 **venv python** 启动；路径含空格（"Glass Agents"）需引号；`chmod` 在 Windows 跳过。hook 内 `subprocess` 用 `sys.executable` 跑 pytest。
- **VS Code 扩展**：面板对自定义 **subagent** 曾有不识别问题，但 **hook / skill 不受影响**；用 `/hooks` 复核注册。
- **config 调用方式**：config 不是后台常驻，而是被 `tools/` 函数在**每次调用时**从磁盘读 —— 改 yaml 即时生效，无需重启或改代码。
