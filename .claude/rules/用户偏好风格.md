# 用户偏好风格

- **语言**：中文回复；简洁、信息密度高，少铺垫和套话。
- **节奏**：增量推进，"走一步看一步"；大改动 / 不可逆操作前先确认。
- **遇歧义或阻塞**：先把问题和推荐项摆出来，**不替用户瞎猜、不编造数值或代号含义**；真正分叉才用提问打断。
- **统计背景**：用户是统计科班出身。解释 ML 概念尽量用统计语言锚定（回归 / 正则化 / 偏差-方差 / 分层抽样 / 响应面…）。
- **缺值处理**：工艺 / 安全常量未知一律 `TODO(plant)`，绝不填占位数字当真值。
- **提交**：非经明确要求不 commit / push；当前在 `master`，要提交先开分支。
- **诚实**：测试失败 / 跳过 / 步骤被略过如实说明，不夸大"已完成"。
- **决策**：能从代码或合理默认推断的就直接做并说明，不做无谓的选项罗列。
