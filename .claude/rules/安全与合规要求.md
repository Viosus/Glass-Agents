# 安全与合规要求

> 钢化工艺安全相关，红线不可破。"规则 > AI"是本项目第一原则。

- **规则 > AI**：任何输出工艺参数的代码路径，落地前必须过 `tools/constraints.validate(p, prev)`；任一项不通过即拒绝该参数集，原样返回 `violations`，**不得自动放宽**。
- **缺值不放行**：阈值为 `TODO(plant)` 未填 → 判"无法判定 → 不通过"，**绝不用占位数字放行**。
- **安全闸门在模型之外**：模型产出的参数仍须过 constraints；安全红线独立强制：
  - `safety.max_gradient`（温度梯度上限）
  - `safety.blowup_rule`（炸板风险判定；缺规则时保守置 `blow_up_risk=True`）
- **提交硬闸门**：`pre_commit_gate` 在 commit 前跑 `pytest`，不过则退出码 2 拦截提交。
- **单位固定**：`℃ / s / mm / nm`，字段名带单位语义，**禁止裸数字**。
- **真值出处**：限值先落源文档再抄进 `config/`，绝不凭空补数。国标分级源 = `docs/《钢化玻璃应力斑分级及检测方法》草案2026.5.18(1).pdf`（原"docs/01"主体，表1/2/3 已抄入 `config/grading.yaml`；草案版，正式版发布后逐值复核）。`docs/03`（硬约束）**仍缺失**；CCP 的 Cmax/CPmax 草案未给，仍 TODO(plant)。
