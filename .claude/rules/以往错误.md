# 以往错误（踩过的坑，别再犯）

> 每条 = 现象 + 根因 + 正确做法。新 session 出现类似征兆先查这里。

## 1. PowerShell here-string `python -c @'...'@` 吞引号
- **现象**：`python -c` 内联多行脚本，字符串引号丢失 → `SyntaxError`（如 `print(torch:, ...)`）。
- **根因**：here-string 经 PowerShell→python 传参时引号被吃掉。
- **正确**：复杂脚本写进临时 `.py` 文件再跑（参考 `check_gpu.py` / `check_env.py`），不要用内联 `-c`。

## 2. 硬闸门被自己的命令误触发
- **现象**：跑一条含 "git commit" 字样的命令（哪怕只是 `echo` 一段 JSON）被 `pre_commit_gate` 拦截。
- **根因**：matcher 命中 `tool_input.command` 里的 "git commit" 子串，触发 pytest。
- **正确**：离线测闸门用**文件喂 payload**（`python .claude/hooks/pre_commit_gate.py < payload.json`），命令行里不要直接出现 "git commit" 字串。
- ⚠️ **Windows PowerShell 子坑**：PS 不支持 `<` 重定向；用 `Get-Content payload.json -Raw | & python hook.py` 喂 stdin **不可靠**——stdin 常为空，`json.load` 抛异常被 `except: sys.exit(0)` 吞掉 → 闸门**假性退 0**（pytest 根本没跑），改坏规则也测不出来。**正确**：`cmd /c '"…python.exe" "…pre_commit_gate.py" < "…payload.json"'`（用 cmd.exe 的 `<` 重定向）。payload 文件**用 Write 工具建**（含 "git commit" 字串，但不是 shell 命令，不触发 PreToolUse 闸门）。

## 3. 用错 Python 解释器
- **现象**：`python` / `python3` 找不到 ML 包或报怪错。
- **根因**：系统 `python`=3.14（无 ML wheel），`python3`=Microsoft Store 假桩（会弹商店）。
- **正确**：一律用 venv 的 `D:\Glass Agents\.venv\Scripts\python.exe`。

## 4. 给不存在的源文档/代号当真值
- **现象**：想引用 `docs/01`、`docs/03` 的国标分级表或 C4/C5 定义。
- **根因**：这些文档当前不存在，C4/C5 从未定义。
- **正确**：缺的标 `TODO(plant)`，绝不凭记忆或推测补数值/补代号含义。

## 5. transformers 5.x 在 Windows 加载大模型原生崩溃（2026-07-02）
- **现象**：`from_pretrained` 加载 Qwen2.5-14B（8 分片 safetensors + bnb 4bit）时进程无 Python 堆栈直接死，
  退出码 `-1073741819`（0xC0000005），faulthandler 显示崩在 5.12 v2 加载器的 mmap 物化
  （`core_model_loading._materialize_copy` → `torch/storage.py __getitem__`）。
- **排查结论**：分片 SHA256 与官方 LFS oid 一致（非损坏）；bnb 小内核 sm_120 正常（非 bitsandbytes）；
  rust `get_tensor` / 单次大偏移 torch 切片单测均正常 → v2 加载器真实负载下的缺陷。
  `disable_mmap=True` 整读路径也不可行：8 分片全量堆内存 ≥28GB，31GB 机器上 safetensors
  rust 侧分配失败 panic（`PyObject pointer is null`）。
- **正确**：**transformers 锁 `<5`**（requirements.txt 已锁；4.57.6 实测 14B 4bit 加载 ≈30s、显存 ≈10GB 正常）。
  以后升 5.x 前必须先跑 14B 冒烟（scratchpad 建 `smoke_teacher_14b.py` 一类脚本）验证。
- ⚠️ **连带小坑**：PowerShell 管道给 python 喂中文默认编码会打乱关键词——先设
  `$OutputEncoding=[Text.Encoding]::UTF8; $env:PYTHONIOENCODING='utf-8'` 再管道（REPL 冒烟同理）。
