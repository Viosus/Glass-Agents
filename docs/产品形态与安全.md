## 一句话
一套**部署在工厂本地、离线运行的多 Agent 调参系统**：投一片玻璃 → 得到一组经安全校验的工艺参数 + 中文操作建议 → 人确认后应用 → 出炉结果回灌持续改进（模仿老师傅）。

## 1. 整体形态（交付物）
不是云服务，而是**装在厂内一台带 GPU 的机器上的本地应用**（RTX 5070 级即可）。组成层次：

| 层 | 内容 | 训练？ |
|---|---|---|
| 确定性层 | `tools/`：质量指标(metrics)、硬约束闸门(constraints)、厚度-时长/对流规则表 | 0 训练（纯代码） |
| 多头核心模型 | 共享编码器 + 参数头/质量头/能耗头/归因头 —— **唯一真正训练的** | 本地训练/QLoRA |
| LLM 角色层 | `llm_roles/`：参数翻译官、知识库问答、Teacher 编排（用本地 Qwen） | 无需训练 |
| 安全闸门 | `tools/constraints.validate` —— **永远在模型之外** | 规则 |
| 数据底座 | `schemas/` + `data/archive/` 归档 + 知识库 | — |
| 护栏 | hooks（提交闸门）、`tools/review.py`（代码审查） | — |

> ⚠️ **交互形态（CLI / 独立 Web / 嵌入 HMI）未拍板**（N1 拍板#4），决定操作工实际界面。

## 2. 文件格式

| 用途 | 格式 | 位置 |
|---|---|---|
| 多头核心权重 | `.safetensors` / `.pt` | 训练产出（gitignore） |
| Teacher LLM | **GGUF**（本地推理） | `models/`（见 VERSION.md） |
| 限值/分级/阈值 | **YAML**（数据驱动，改即生效） | `config/*.yaml` |
| 样本/标签 | **JSONL**（一行一片，ArchiveSample） | `data/archive/` |
| 应力斑图像 | 图像文件，**路径+sha256 与结构化数据分离** | 专用图像目录 |
| 知识库 | **JSONL**（QAPair） | `data/kb/qa_pairs.jsonl` |
| 数据契约 | pydantic（写入即校验） | `schemas/` |
| 产出参数 | **JSON**(ProcessParams) → 中文建议文本 | 运行期 |
| Prompt 模板 | Markdown（占位符） | `config/prompt_*.md` |

## 3. 使用方法（端到端一条样本）
```
投一片玻璃
 → 扫描仪出应力斑图像 + PLC/MES 出工况
 → tools/metrics 算 X0.95/IsoT/CCP（仅掩膜内）
 → 多头核心（冷启动期为 Teacher）产 参数 + 理由
 → tools/constraints.validate 安全闸门 ← 不过则拒，返回 violations
 → llm_roles/param_translator 转中文操作建议（数值确定性，LLM 只润色）
 → 老师傅复核/修正（人在环）→ 标 is_ground_truth 入库
 → 应用到炉子 → 出炉实测质量/能耗 回填该样本
 → 攒够数据 → 周期重训多头核心（飞轮）
```
辅助：`llm_roles/kb_qa` 随时回答工艺问题（只据现有 docs，缺值拒答）。

## 4. 商业安全如何保障

### A. 生产/工艺安全（防炸板、防错误参数）
- **规则 > AI**：任何出参**强制过 `constraints.validate`**，任一不过即拒、原样返回 `violations`，**绝不自动放宽**。
- **缺值不放行**：安全/国标常量为 `TODO(plant)` → 判"无法判定→不通过"，**绝不用占位数放行**。
- **安全红线独立**：温度梯度上限、炸板判定规则；缺规则时**保守置为有风险**。
- **人在环**：系统出"建议"，老师傅**最终拍板**——助手而非替代，责任可归属。
- **工程闸门**：提交前 pytest 硬闸门 + `review.py` 机械审查（双通道：确定性❌+模型⚠️）。

### B. 商业机密/数据安全（防工艺配方泄露 —— 工厂核心资产）
- **本地无云**：配方、图像、MES 数据**不出厂**；本地 GGUF 推理 + 本地训练，**不接外部云 API / 外部 MCP** → 从源头杜绝外流。
- **涉密取数走自定义适配器**：PLC/MES/扫描仪接口用项目内代码，不接第三方。
- **审计留痕**：每片玻璃的 参数+理由+出处+操作员id 全归档（ArchiveSample），可追溯、可复盘标签一致性。
- **知识库禁编造**：问答只据现有资料 + 标出处，缺值拒答 → 防错误工艺被"自信地"扩散。
- **上线门槛**：N5 影子运行验证门 —— 质量不回归 + 约束零违规才允许真正下发。

### C. 商用前必须补、但目前**不存在**的安全项（诚实清单）
- [ ] **访问控制 / 操作权限**：谁能改 config、谁能下发参数 —— 无。
- [ ] **软件授权 / license / 防拷贝** —— 无。
- [ ] **配置/模型防篡改**：改限值 yaml 的审批与运行期签名校验 —— 仅有 git + 提交闸门，无运行期校验。
- [ ] **数据加密落盘 / 备份策略** —— 未规划。

> 这几项属空白，商业化交付前需专门补一轮"运维与准入"设计。
