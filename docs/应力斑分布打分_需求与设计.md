# 应力斑分布打分 · 需求与设计

> 代码位置：`fringe_scoring/`　|　配置：`config/fringe_scoring.yaml`　|　测试：`tests/test_fringe_scoring.py`
> 状态：v0 已实现（合成图验证）；真实图与人工打分到位后进入校准迭代（见 §6）。

## 1. 背景与需求

工业上对玻璃应力斑只有定性要求「**淡且均匀**」，没有数值标准。本工具把这句话操作化为一个可比较的分数：
**斑越深、越集中于玻璃中心 → 分越低；越淡、越靠边 → 分越高**。

### 已确认的需求决策
| # | 决策 | 内容 |
|---|---|---|
| 1 | 斑/背景区分 | 每片玻璃深浅不固定 → 逐片稳健标准化（median/MAD 的 z 分数，先扣除大尺度背景照度）；**斑判定默认分位数法**：取偏离背景最深的 top 10%–20% 像素，比例按斑占总面积的经验占比调（`segment.top_fraction`） |
| 2 | 中心定位 | 输入图像**已裁切、玻璃占满整图** → 中心 = 图像几何中心；长、宽分别归一化，每个像素定位在 [-1,1]×[-1,1] |
| 3 | 位置惩罚 | 离中心越远惩罚权重越低（默认线性 1−r），**加权公式可调**（见 §4 调参指南） |
| 4 | 边框剔除 | 玻璃边框必有重应力斑、宽窄不一 → 四边各自**自适应检测**带宽并剔除，不计入惩罚；但归一化坐标仍按整块玻璃（含边框）计算 |
| 5 | 斑的极性 | 暗斑、亮斑都算（相对背景的绝对偏离 \|z\|），config 可切 bright/dark |
| 6 | 输出口径 | 0–100 分（越高越好）+ 原始惩罚值两者都给 |
| 7 | 数据现状 | 真实图像稍后放入 `data/images/stress_fringe/`（当前尚无人工打分）；之后会有**带人工打分**的图片用于校准 |
| 8 | 四边形玻璃 | 图片由**大图裁切**（一张大图多片玻璃），单片可能是平行四边形/一般四边形；四边形外为无信息填充（近恒定）。**无角点元数据 → 自动检测**（`--corners` 显式角点兜底）；路线=**透视矫正成矩形**后走原流水线 |
| 9 | 同心四边形归一化 | 离中心远近 = 像素落在哪一圈与玻璃同形的同心缩放四边形。实现 = 矫正域 **chebyshev** 距离（同心矩形等罚线映射回原图即同心四边形），设为新默认；euclidean 保留可切 |
| 10 | **交付形态** | 本工具**最终缝入外部正规工业检测软件**，不在 Glass Agents 项目内直接使用——本仓库只是它的开发/验证环境。输出格式到集成时再转，但核心模块必须保持可拔出（见 §5.5） |

## 2. 算法流水线

```
图像 (二维数组，.npy 或位图灰度，schemas/image_io.load_array 读入)
 │
 ├─ ⓪ 四边形检测与透视矫正（fringe_scoring/quad.py）：
 │      边界一圈找"恒定值尖峰"估填充 → 玻璃掩膜(|图像−填充|>tol) → 最大轮廓凸包
 │      → approxPolyDP 拟合 4 角（epsilon 梯级放大，收不到 4 点报错）→ 矫正成矩形
 │      （目标宽/高=对边平均长）。无填充尖峰/玻璃占满整图/近恒定图 → 不矫正走原路径；
 │      玻璃占比异常低 → 报错拒绝打分。显式角点可经 quad_corners / --corners 传入。
 ├─ ① 背景估计（两遍）：先按带宽上限扣除四边，内部**分块中位 + Tukey-IRLS 稳健拟合
 │      低次多项式曲面**（默认平面），整图求值 → 预残差 = 图像 − 预背景。
 │      背景=全局低次曲面的理由：只吸收照度渐变等大尺度趋势，吸收不了紧凑的应力斑；
 │      斑/边框所在块被 Tukey 权重当离群点压零（局部中值滤波在"斑比窗宽"时会把斑
 │      吸进背景，边框在边缘邻域占多数时更会被当成局部背景，都试过、都被合成图打回）
 ├─ ② 边框带检测：|预残差| 按行/列取分位数得 1D 剖面，从四边向内扫描：
 │      剖面 > 中段基线 + 内部波动×ratio 视为仍在带内（纯局部判据，不做拟合外推——
 │      外推杠杆会把微小误差放大成边缘假偏离）；带宽 clip 到 [min,max]×边长。
 │      定完带宽后按实测带宽重估终版背景 → 残差
 ├─ ③ 稳健 z：median/MAD 只在"非边框内部"估计（污染剔除后再估尺度）
 │      z = (residual − median) / (1.4826×MAD)；MAD≈0 → 判定无斑（防止把数值噪声放大成斑）
 ├─ ④ 斑分割：dev = |z|（或单极性）
 │      quantile 法（默认）：内部像素 dev 的 top_fraction 分位为阈值，且 dev≥min_z
 │        才算斑（质控下限：纯噪声玻璃虽被硬选 top-q，弱偏离不计罚）
 │      robust_z 法（备选）：固定阈值 z_threshold
 │      深浅强度 s = clip(dev / z_saturation, 0, 1) —— 锚定统一 z 尺度，跨玻璃可比；
 │      好玻璃即使被硬选 top-q，其 s≈0，惩罚≈0
 └─ ⑤ 打分：见 §3
```

## 3. 打分公式

- 归一化坐标：`u = 2(col+0.5)/cols − 1`，`v = 2(row+0.5)/rows − 1`（矫正后图=整块玻璃，含边框）。
- 中心距离（默认 chebyshev）：`r = max(|u|,|v|)`——等罚线是同心矩形，经透视矫正映射回
  原图即**与玻璃同形的同心四边形等高线**；可切 euclidean：`r = √(u²+v²)/√2`（椭圆等罚线）。
- 位置权重：`w(r) = 1 − r`（linear，默认）或 `w(r) = exp(−r²/2σ²)`（gaussian）。中心权重最大 → 中心的斑罚最重。
- 惩罚：`penalty_raw = Σ_{斑像素，且∉边框带} s·w(r)`。
- 归一化基准（纯几何，不依赖现场真值）：`penalty_max = Σ_{非边框全部像素} 1·w(r)`（最差情形=有效区全是最深斑）。
- **`score = 100 × (1 − penalty_raw / penalty_max)`**；无斑 → 100。
- 诊断输出：斑面积占比 `fringe_area_frac`、集中度 `centrality`（s 加权平均 w，越大越集中于中心）、四边带宽 px。

## 4. 调参指南 ⭐（惩罚加权公式该调哪几个数字）

全部参数在 `config/fringe_scoring.yaml`，**运行时读取，改 yaml 即生效**。直接影响惩罚加权公式的是下面 5 个：

| config 键 | 默认 | 含义 | 调大的效果 | 调小的效果 |
|---|---|---|---|---|
| `weight.kind` | `linear` | 权重形状：`linear`=1−r 缓降；`gaussian`=中心尖峰 | — | — |
| `weight.gaussian_sigma` | 0.5 | gaussian 形状的"中心区半径"（r 的单位，0~1） | 惩罚范围向边缘铺开，接近"处处同罚" | 只有贴着中心的斑挨重罚，边上的斑几乎免罚 |
| `weight.distance_norm` | `chebyshev` | 距离口径：`chebyshev`=同心矩形等罚线（矫正映射回原图=同心四边形等高线，本次需求语义）；`euclidean`=椭圆/圆形 | — | — |
| `segment.z_saturation` | 8.0 | 深浅 s 封顶的 z 值（多深算"最深"） | 深斑之间更拉得开差距，但整体惩罚变轻 | 中等深度就顶满，惩罚更狠、更早饱和 |
| `segment.top_fraction` | 0.15 | 分位数法圈定的斑面积占比（按经验斑占比定，建议 0.10–0.20） | 圈进更多浅斑，分数整体走低 | 只认最深的一小撮，分数整体走高 |
| `segment.min_z` | 2.5 | 计罚的质控下限：top-q 且 \|z\|≥该值才算斑 | 只罚明显的斑，干净玻璃更接近满分 | 噪声级偏离也计罚，分数整体走低 |

次要但可能要动的：

| config 键 | 默认 | 什么时候动 |
|---|---|---|
| `segment.method` | `quantile` | 想改用固定 z 阈值判斑时切 `robust_z`（配 `z_threshold`） |
| `segment.polarity` | `both` | 确认斑只偏亮或只偏暗时切 `bright`/`dark` |
| `segment.background_block_frac` | 0.05 | 背景拟合的分块边长≈内部短边×该比例；斑普遍比块还小时可调小 |
| `segment.background_poly_degree` | 1 | 背景曲面次数：1=平面（默认，稳）；照度明显弯曲才升 2——宽斑会污染曲率项（穹顶假象），改后必须目检 |
| `segment.min_contrast_frac` | 0.05 | 残差尺度低于图像整体尺度×该比例 → 判"无斑"；误把平滑玻璃判出斑时调大 |
| `quad.auto_detect` | true | 四边形自动检测总开关；关掉则按"整图即玻璃" |
| `quad.fill_tol_frac` | 0.05 | 填充判定容差=图像稳健尺度×该比例；填充有轻微噪声/压缩伪影时调大 |
| `quad.min_fill_border_frac` | 0.2 | 边界"恒定填充尖峰"占比低于此判无填充；误把整图玻璃当四边形时调大 |
| `quad.full_frame_frac` / `min_glass_frac` | 0.99 / 0.5 | 玻璃占比≥前者跳过矫正；<后者（且非近恒定图）报错拒绝 |
| `quad.poly_epsilon_frac` | 0.02 | 四角拟合精度（凸包周长×该比例，内部会梯级放大重试）；圆角/毛边玻璃调大 |
| `border.max_band_frac` / `min_band_frac` | 0.25 / 0.0 | 边框带宽的保护上下限（占对应边长比例） |
| `border.profile_quantile` | 0.75 | 边框剖面取每行/列的该分位数；边框不连续（局部重）时调高更敏感 |
| `border.return_to_background_ratio` | 2.0 | \|去趋势剖面\| 回落到内部波动（稳健σ）×该倍数以下算出了边框带；边框剔太窄调小、剔太宽调大 |

## 5. 用法

```powershell
$py = "D:\Glass Agents\.venv\Scripts\python.exe"
& $py fringe_scoring\run_score.py <图路径.npy|.png|.tif> [更多图...]   # 打分（自动检测四边形并矫正）
& $py fringe_scoring\run_score.py <图路径> --viz-dir out\              # 另存可视化四联图
& $py fringe_scoring\run_score.py <图路径> --corners "60,10;355,25;320,245;25,230"  # 显式角点
& $py fringe_scoring\run_score.py <图路径> --no-quad                   # 关自动检测（整图即玻璃）
& $py fringe_scoring\run_score.py --demo                               # 合成四图对照演示
```

Python API：

```python
from fringe_scoring import score_fringe_distribution
from schemas.image_io import load_array

res = score_fringe_distribution(load_array("data/images/stress_fringe/0001.png"))
print(res.score_0_100, res.penalty_raw, res.fringe_area_frac, res.centrality)
```

## 5.5 交付形态与嵌入边界 ⭐

本工具的归宿是**外部工业检测软件**，不是 Glass Agents 内部组件。
**集成方操作手册见 [应力斑分布打分_导出嵌入指南.md](应力斑分布打分_导出嵌入指南.md)**（拔出清单/依赖/配置注入/输入输出契约/错误契约/冒烟自检）。据此的架构纪律：

- **可拔出核心（随交付走）**：`fringe_scoring/{__init__,segment,border,quad,score}.py` 五个文件，
  自包含（只有包内互引，**零仓库耦合**）。第三方依赖：`numpy`（必需）、`opencv`（仅四边形
  矫正路径用，函数内延迟导入）、`pyyaml`（仅走 yaml 读配置时用，延迟导入——嵌入方用
  `score_fringe_distribution(image, config=dict)` 注入配置则完全不需要）。
- **开发壳（不随交付走）**：`run_score.py`（CLI/可视化，引 matplotlib 与仓库 `schemas.image_io`）、
  `synth.py`（合成数据）、`tests/`、`config/fringe_scoring.yaml`（参数的**内容**要带走，载体随
  嵌入方定：yaml / json / 软件自己的配置系统均可，最终都是喂 dict）。
- **纪律**：今后任何改动**不得**往核心五文件里引 Glass Agents 其他层（schemas/tools/训练栈）；
  新增依赖先想"嵌入方装不装得起"。
- **输出契约**：当前 = `FringeScoreResult` dataclass（标量结果 + 诊断 numpy 图层，见 §5）。
  集成时按检测软件的接口再转（JSON/C 结构体/数据库行均可从该 dataclass 平移），字段语义以
  本文档 §3 为准。

## 6. 校准路线（真实数据到位后）

1. **迭代①（图片放入，无人工打分）**：`run_score.py` 跑真实图 + `--viz-dir` 出可视化，人工目检
   斑分割是否符合直觉、边框带是否剔干净 → 回调 §4 参数。
2. **迭代②（带人工打分的图片到位）**：算法分 vs 人工分做 **Spearman 秩相关**（打分只要求排序一致，
   不追求线性对齐）；按秩相关最大化调 `weight.*` / `segment.*`；必要时再加单调映射把分数标到人工口径。

## 7. 开放问题（挂账）

- [ ] 打分验收口径：多少分算「淡且均匀」合格？→ 待人工打分样本定（迭代②）。
- [ ] `top_fraction` 的真实经验值：斑通常占总面积百分之多少？→ 真实图目检后定。
- [ ] 真实图像的位深/通道/朝向是否统一？是否需要预处理（去噪/直方图裁剪）？→ 图片到位后看。
- [ ] 本打分与国标三指标（X0.95/IsoT/CCP，`tools/metrics.py`）的关系：并列输出还是加权合成？→ 现场定。
- [ ] **四边形检测的填充假设**：当前假设四边形外为近恒定填充（边界尖峰法）；真实裁切图到位后
      首要目检项——不满足时走 `--corners` 显式角点，或按实际填充形态改检测策略。
- [ ] 非凸 / 圆角 / 毛边四边形：approxPolyDP 收不到 4 点会报错（不静默降级）；真实图看是否需调
      `poly_epsilon_frac` 或加圆角处理。
- [ ] **矫正插值的系统偏差**：透视矫正会轻微平滑噪声 → 稳健 z 锚收紧 → 经矫正的图比未矫正的
      系统性偏严约 2–3 分（同族内部排序不受影响，真实裁切图全走矫正路径互相可比）；与人工分
      校准时此偏差会被一并吸收。
