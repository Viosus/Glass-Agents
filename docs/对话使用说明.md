# 对话使用说明（CLI 对话壳）

> `llm_roles/dialogue.py` + `run_dialogue.py`：终端里多轮聊——改参数、查合规、看样片指标、问工艺。
> 边界先说死（规则 > AI）：**所有数值来自确定性工具，LLM 从不产数字**；诊断只报数不下结论（类目 TODO(plant)）。

## 1. 启动

```powershell
$py = "D:\Glass Agents\.venv\Scripts\python.exe"
& $py llm_roles\run_dialogue.py --no-llm                          # 全确定性，秒开（推荐日常）
& $py llm_roles\run_dialogue.py --no-llm --furnace-id F1 --baseline 基准配方.json
& $py llm_roles\run_dialogue.py --no-llm --sample data\archive\xxx.json   # 载入样片(含指标/分数)
& $py llm_roles\run_dialogue.py                                   # 加载本地 Qwen：润色+意图兜底(CPU 慢)
```

## 2. 能听懂什么（意图与示例话术）

| 意图 | 示例 | 行为 |
|---|---|---|
| 改参数 | 「上炉温改到705」「加热时长调到220，下炉温降到690」 | 正则抽数 → `constraints.validate(新, prev=旧)` → 过 = 中文骨架呈现；不过 = 只列 violations **禁止照做** |
| 查参数 | 「检查当前参数」「这组合规吗」 | 当前参数过闸门 → 呈现 |
| 要建议 | 「给个建议」「模型怎么看」 | 已激活参数头出 Δ → 确定性解码 → **过闸门** → 呈现 Δ 明细+建议；**不自动应用**，认可哪项说「XX改到YY」逐项确认（再过一次闸门） |
| 出参数单 | 「导出参数单」「出个表」 | 当前参数导出 **Excel 参数单**（`data/outbox/`；含基准/Δ 列与闸门状态，未过闸门标注"禁止照此操作"+问题清单） |
| 看参数 | 「当前参数」 | 确定性中文骨架（数值唯一来源） |
| 诊断 | 「诊断一下」「这片应力斑怎么样」 | 呈现样片已带指标（X0.95/IsoT/CCP 判级 + 外部 fringe 分布分）；**只报数** |
| 问工艺 | 「为什么上炉温要高于下炉温」 | 词法检索知识库；缺依据/缺值**拒答不编造**；无 LLM 时直呈命中问答对+出处 |
| 帮助/退出 | 「帮助」「退出」 | — |

支持的参数叫法（`config/dialogue_rules.yaml` field_aliases，现场可补词，改完即生效）：
上炉温 / 下炉温 / 对流风速(风速) / 上下对流配比(对流配比) / 摆动速度 / 摆动幅度 / 加热时长(加热时间)。
**分区温度暂不支持对话修改**（zone_temps 不在 Δ 契约内，待参数头字段空间扩展后放开）。

## 3. 行为边界（务必知晓）

1. **数字绝不来自 LLM**：改参的数值用正则从你的原话里抽；模型建议的数值来自参数头+确定性解码并强制过闸门；读不到数值会反问，不猜。
   模型来源：注册表**当前激活版本**（`--registry`，无激活版本则该意图如实提示不可用；调试可 `--model-weights` 直指权重）。
2. **每次改参都过安全闸门**，且带上一轮参数做 prev（单次调温幅度 C1-d 靠它）。当前 config 多项
   TODO(plant) → 闸门**如实全拦**是预期行为，填了真值（见《信息需求清单》板块 A）即解锁。
3. **越界只呈现 violations**，不给"照做"建议；改的值仍记在会话里供你继续试算。
4. 听不懂 → 有 LLM 时先让它做单标签意图分类（输出限枚举，非枚举按听不懂）；仍不懂就**反问**。
5. 多轮记忆在确定性会话状态里（参数/上一轮参数/最近检查/全部对话留痕），不依赖 LLM 上下文。
