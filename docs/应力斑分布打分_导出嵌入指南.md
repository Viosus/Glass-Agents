> 面向：把本工具**缝入外部正规工业检测软件**的集成方。
> 算法语义与调参见姊妹文档 [应力斑分布打分_需求与设计.md](应力斑分布打分_需求与设计.md)（下称"设计文档"）。
> 本仓库（Glass Agents）只是开发/验证环境，导出后与仓库再无关系。

## 1. 拔出清单

只拷贝这**七个文件**，保持 `fringe_scoring/` 包目录结构：

```
fringe_scoring/
├── __init__.py    # 公共 API 出口
├── segment.py     # 背景曲面拟合 + 稳健 z + 斑分割
├── border.py      # 四边边框带自适应检测
├── quad.py        # 四边形玻璃检测 + 透视矫正
├── score.py       # 打分编排 + 结果 dataclass（单片）
├── sheets.py      # 整床多片切分 + 逐片打分 + 汇总（一张照片多块玻璃）
└── indicators.py  # 六指标测量（X0.95/灰度方差/梯度均值/梯度方差/CCP/位置评分）+ 可调加权总分
```

**不要带走**：`run_score.py`（CLI/可视化开发壳，引仓库内部模块与 matplotlib）、`synth.py`（合成数据）、`tests/`、`config/fringe_scoring.yaml`（其**参数内容**要带走，见 §3；yaml 文件本身只是开发期载体）。

七文件自包含（只有包内互引，零仓库耦合；GLCM 为 numpy 自实现，无 skimage 依赖）。
如果检测软件不是 Python 栈，见 §7 集成形态。

## 4. 输入契约

- **二维灰度 numpy 数组**（float 或可转 float），一张 = 一片玻璃的裁切图。
- 彩色图先自行转灰度（任意常规加权均可）。
- ⚠️ **灰度尺度契约（默认 `s_scale_mode: absolute`）**：深浅惩罚用绝对灰度锚，**同一套
  `s_saturation_gray`/`min_dev_gray` 只对同一成像条件（曝光/增益/位深）有效**——换条件需重标
  （见 §9）。仅在切到 `per_sheet` 旧口径时，算法才对逐片仿射变换（整体加常数/乘正系数）不变；
  该口径已实测会把"整片重斑"漏罚（排序反转），不推荐。
- 玻璃可为正矩形（占满整图）或平行四边形/一般**凸**四边形（外部为近恒定填充）；四边形自动检测，也可传显式角点：

```python
res = score_fringe_distribution(image, config=FRINGE_CONFIG)                 # 自动
res = score_fringe_distribution(image, config=FRINGE_CONFIG,
                                quad_corners=np.array([[60,10],[355,25],[320,245],[25,230]]))
# 角点为 (x=列, y=行) × 4，顺序任意（内部会重排为左上→右上→右下→左下）
```

**整床多片模式（`score_sheets`）**：一张照片含多块玻璃时用此入口，自动切片后逐片打分：

```python
from fringe_scoring import score_sheets

bed = score_sheets(image, config=FRINGE_CONFIG)   # 需要 config 含 sheets 段
bed.n_sheets        # 检出片数
bed.scores          # 逐片分数（阅读序：先行后列）
bed.score_min       # 最差片（整床验收最相关）
bed.sheet_results   # 逐片完整 FringeScoreResult（含各片角点 quad_corners_px，原图坐标）
bed.sheet_indicators  # 逐片六指标 SheetIndicators（config 含 indicators 段时；详见下）
bed.total_scores / bed.total_min / bed.total_mean  # 六指标加权总分及汇总
```

**六指标（`SheetIndicators`，测量软件的主输出）**：每片输出六项原始值 + 0–100 子分 +
加权总分。权重（`indicators.weights`，默认平权）与好差参考值（`indicators.refs`）都在
config 中，**工厂在软件配置里即可调整加权公式**，改后立即生效：

| 字段 | 含义 | 方向 |
|---|---|---|
| `x095` / `x095_unit` | 95% 分位光程差；未标定 gray_to_nm 时为灰度代理（unit="gray"） | 低好 |
| `gray_variance` | 内部灰度方差 | 低好 |
| `gradient_mean` / `gradient_variance` | Sobel 梯度幅值均值 / 方差 | 低好 |
| `ccp_value`（附 `ccp_ca`/`ccp_cpa`） | 组合纹理特征（GB 草案公式口径） | 低好 |
| `center_concentration` | 应力斑中心集中度 ρu（位置指标主量，与深浅解耦） | 低好 |
| `position_score`（原 `uniformity`，2026-07-19 改名） | 位置评分=ρu 经刻度锚 ρ0 换算（全白图=100） | 高好 |
| `sub_scores` / `weights` / `total_score` | 六子分、当次权重快照、加权总分 | 总分高好 |

**斑/背景二值划分图**：每片的 `FringeScoreResult.fringe_mask`（布尔阵，True=判为应力斑）
即二值化掩膜，白=斑、黑=正常，直接可视化；开发壳 `--store-dir` 会逐片导出
`sheetNN_mask.png` 与并排对照 `sheetNN_overlay.png`。

多片模式的成立前提（不满足时检测报 `ValueError`，转人工）：暗场成像（无玻璃处为暗背景，
玻璃片边缘偏亮）；暗背景占比 ≥ `sheets.bg_quantile`（默认 25%）。照片首末行的 1px 亮线
artifact（部分导出软件所加）已由 `edge_trim_frac` 裁边处理。

## 5. 输出契约（`FringeScoreResult`）

| 字段 | 类型 | 含义 |
|---|---|---|
| `score_0_100` | float | **主输出**：0–100，越高越好（惩罚的纯几何归一化，跨玻璃可比） |
| `penalty_raw` / `penalty_max` | float | 原始惩罚 / 最差情形基准（score = 100×(1−raw/max)） |
| `fringe_area_frac` | float | 斑面积占非边框有效区比例 |
| `centrality` | float \| None | 集中度（斑深浅加权平均位置权重；None=无斑） |
| `border_bands` | BorderBands | 四边边框带宽 px（`.top_px/.bottom_px/.left_px/.right_px`） |
| `quad_corners_px` | ndarray(4,2) \| None | 检出/传入的角点（原图坐标）；None=整图即玻璃未矫正 |
| `intensity_s` / `fringe_mask` / `border_mask_arr` / `weight_map` / `warped_image` | ndarray | 诊断图层（矫正域坐标），供人工复核界面渲染；入库通常不存 |

标量部分转 JSON 示例：

```python
def result_to_record(res) -> dict:
    """打分结果 → 可入库的扁平记录（诊断图层不进）。"""
    b = res.border_bands
    return {
        "score_0_100": res.score_0_100,
        "penalty_raw": res.penalty_raw,
        "penalty_max": res.penalty_max,
        "fringe_area_frac": res.fringe_area_frac,
        "centrality": res.centrality,
        "border_px": [b.top_px, b.bottom_px, b.left_px, b.right_px],
        "quad_corners_px": None if res.quad_corners_px is None else res.quad_corners_px.tolist(),
    }
```

## 6. 错误契约与运行特性

- **失败 = 抛 `ValueError`，绝不返回瞎猜的分数**（规则 > AI）。需捕获并转人工复核的情形：
  - 四边形检测异常（玻璃占比过低 / 轮廓拟合不出 4 角）；
  - 多片切分异常（一片都检不出 / 片数超 `max_sheets` 疑似过分割）；
  - 配置非法（未知枚举、参数越界、缺段）。
- **无状态、确定性**：纯函数，无全局可变状态、打分路径无随机数——同一输入+配置永远同一输出；可多线程/多进程并发，每图独立。
- 常量图/无纹理图安全退化为满分 100（判"无斑"），不会除零崩溃。

## 8. 目标环境冒烟自检（不依赖本仓库）

拷贝后在目标环境跑通以下三条即视为移植成功：

```python
import numpy as np
from fringe_scoring import score_fringe_distribution

cfg = FRINGE_CONFIG  # §3 的配置（默认 s_scale_mode=absolute）
r1 = score_fringe_distribution(np.full((200, 300), 50.0), config=cfg)
assert r1.score_0_100 == 100.0                     # 常量图=无瑕玻璃满分

rng = np.random.default_rng(0)
img = 100 + rng.normal(0, 1, (200, 300))
yy, xx = np.mgrid[0:200, 0:300]
blob = np.exp(-((yy - 100) ** 2 + (xx - 150) ** 2) / (2 * 16 ** 2))
r2 = score_fringe_distribution(img + 30 * blob, config=cfg)   # 中心淡斑
r3 = score_fringe_distribution(img + 90 * blob, config=cfg)   # 同位置更深的斑
assert r2.score_0_100 < r1.score_0_100                        # 有斑必扣分
assert r3.score_0_100 < r2.score_0_100                        # 绝对锚：越深罚越重（跨片可比）
```

（若切 `per_sheet` 旧口径，第三条断言改为仿射不变：`1.7*img+33` 分数不变。）

## 9. 已知事项（集成前须知）

- **矫正插值偏差**：经四边形矫正的图比未矫正的系统性偏严约 2–3 分（插值平滑噪声 → z 锚收紧）。生产图若全走矫正路径则互相可比；混用两种路径时注意口径（设计文档 §7）。
- **验收阈值未定**：多少分算「淡且均匀」合格，待人工打分样本校准后确定；校准同时会吸收上一条偏差。
- **填充假设**：四边形自动检测假设四边形外为近恒定填充；不满足时用 `quad_corners` 显式角点。
- **面积/极性/边缘口径**（2026-07-03 决策 #12）：默认 `gray_threshold`+`bright`+`floor=0.3`——斑面积
  不封顶（铺得越大罚越多）、只算偏亮（暗场物理，杜绝斑占多数时干净暗区被反标）、边缘重斑不免罚。
- **暗地板锚 + 边框带语义**（2026-07-03 决策 #13）：背景块统计取低分位（`background_block_quantile=0.15`），
  整片布满亮斑时背景仍锚在暗地板——"均匀饱和"不再漏罚；边框带只免罚 `normal_band_frac=0.04` 的
  细圈（物理正常），超宽带段按普通斑计罚（带宽过大=质量缺陷）。残余极端：连块内暗隙都没有的
  完全饱和片理论上仍会低估，出现此类片联系开发方引入整照暗参考。
- **绝对锚常数须按成像条件标定**（2026-07-02 决策 #11）：默认深浅锚为固定灰度
  （`s_saturation_gray=200`/`min_dev_gray=10`，按 2026-07 实测批次 400US/F4/255 定：最重斑片斑内
  p99≈200–228）。**换相机/曝光/增益/位深必须重标这两个常数**，否则分数不可比。历史背景：旧的
  逐片 z 锚（per_sheet）在"整片重斑"上排序反转（算法最高分=人眼最差），已实测修正
  （Spearman 分数-绝对涨落从 +0.63 → −0.82），保留仅作曝光不可控时的退路。
- **多片切分默认值以 2026-07 实测五张整床照片调定**（8/4/2/1/10 片全部正确切出）：`fg_min_rel`
  实测 ≥0.2 才能断开相邻片边缘辉光的粘连，0.2–0.5 区间计数稳定 → 默认 0.25。换相机/曝光/
  工装后先跑一批照片人工核对片数，再按 `config` 注释调 `sheets` 段。
- **版本追溯**：导出时记录来源 commit（`git log -1 --format=%H -- fringe_scoring/`），便于日后对齐算法版本。
