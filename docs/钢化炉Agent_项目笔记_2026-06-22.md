## 3. 关键架构决定（记一笔，免得忘）

**不做 6 个独立小模型再拼接。** 原因：6 个 agent 不是同一种东西。按"计算类型"重新切：

- **确定性层（代码，0 训练）**：应力斑指标（M1 的一部分）、硬约束（M6）、设备损耗公式（M4）、厚度-时长 / 对流规则表。6 个 agent 里一大半其实落在这。
- **感知小模型（可选）**：M1 里图像→特征中真正要学的部分；可先用经典 CV / 指标顶着。
- **一个多头核心模型（唯一要训练）**：输入〔感知特征 + 指标 + 配方 + 设备 + 工况〕→ 参数。多头 = 共享一个编码器，挂参数头 / 质量头 / 能耗头 / 归因头。它吸收了 M2（归因隐含）、M5（就是模仿专家）、M3 的参数生成。
- **安全闸门永远在模型之外**：模型出的参数仍过 `constraints.py`。

**多头为什么帮小数据（一句话版）**：让稀缺的专家标签只负责学"最后一公里"的决策；把"读懂这炉玻璃"这件最吃数据的事，交给海量免费的实测质量 / 能耗标签去训练共享表示。

## 4. 术语表（中英对照 · 按统计本科基础解释）

> 用你已经熟的统计概念（回归、过拟合、偏差-方差、正则化、响应面、同分布假设…）来锚定这些 ML 词。

### 学习范式

- **监督学习 Supervised learning** — 就是你熟的回归 / 分类：有 (x, y) 对，拟合 f: x→y。本项目大部分模型属于此。
- **模仿学习 / 行为克隆 Imitation learning / Behavior cloning** — 监督学习的一种，响应变量 y = 专家的动作。这里 x = 这炉玻璃的状况，y = 老师傅最终设的参数。本质就是"把专家怎么做"当回归目标拟合。
- **知识蒸馏 Knowledge distillation** — 用一个能力强的大模型（teacher）的输出当标签，去训练一个小模型（student）。关键是用"软标签"（见下）而非只用真值。类比：老师不只告诉你答案，还告诉你每个选项的可能性，信息更丰富。
- **强化学习 / 离线 RL Reinforcement / Offline RL** — （v1 暂不用，后期可选）不靠"专家动作"标签，而靠"结果好坏"（奖励）来学。先做模仿，不够用再升级。

### 模型结构

- **编码器 / 主干 Encoder / Backbone** — 把原始输入先压成一组特征（类似 PCA 学出来的低维表示，但是端到端学的、非线性的）。多个头共用它。
- **头 Head** — 接在编码器后、对应某个具体输出的小模块（通常一两层）。多头 = 一个主干上接多个头。
- **表示 Representation** — 编码器输出的那组特征向量；"学到好表示" ≈ 学到一组能把任务做好的自变量。
- **策略 Policy** — 从状态到动作的映射函数 π: 状态 → 参数。"策略模型"就是学这个映射。
- **残差策略 Residual policy** — 预测"相对基准配方的调整量 Δ"而非绝对参数值。类比：回归里对基线建模 / 中心化，只学偏离量，更稳、更省样本。
- **前向 / 代理模型 Forward / Surrogate model** — 学 f(状态, 参数) → 结果（质量 / 能耗）的回归，用来"预测这样设会怎样"，可代替真实试炉做搜索。统计里的**响应面方法（response surface）**就是同类思想。

### 为什么帮小数据

- **辅助任务 / 辅助监督 Auxiliary task / supervision** — 除主任务外额外加的预测任务（质量 / 能耗 / 原因）。即使你只在乎主任务，它们也能改善共享表示。
- **正则化 Regularization** — 你熟的：给损失加约束防过拟合（岭 / lasso）。辅助任务是另一种正则化 —— 逼模型同时解释别的响应，等于加了额外约束。
- **偏差-方差 Bias–variance** — 你熟的：小样本下单任务模型**方差大**（过拟合）；多任务 / 正则化通过降方差换一点偏差，提升泛化。
- **归纳偏置 Inductive bias** — 模型或训练方式自带的"倾向性先验假设"。类比：线性回归假设线性关系，就是一种归纳偏置；让模型去预测"原因"会偏置它学出可分解的表示。
- **负迁移 Negative transfer** — 多任务里某个任务和主任务"打架"，反而拖累主任务。靠损失加权缓解。
- **损失加权 Loss weighting**（如 不确定性加权 / GradNorm）— 给各任务的损失项配不同权重，平衡它们对共享主干的拉扯，避免某任务主导或负迁移。

### 数据与标签

- **标签 / 真值 Label / Ground truth** — 训练用的"正确答案" y。本项目最贵的真值 = 老师傅复核后的最终参数。
- **硬标签 vs 软标签 Hard vs Soft label** — 硬 = 确定的类别 / 数值（如 0/1）；软 = 概率分布或连续打分（如各类别概率）。蒸馏用软标签，信息量比硬标签大。
- **弱监督 Weak supervision** — 标签不完美或间接获得（从专家动作反推、从 teacher 反推），不是金标准人工标注。够用即可。
- **分桶 / 分层 Bucketing / Stratification** — 按厚度、品类分组分别统计与训练。类比：**分层抽样 / 分层分析**，避免不同子总体被混在一起算。

### 运行与部署

- **多目标优化 Multi-objective optimization** — 同时优化多个目标（省能耗 + 省损耗），并在约束下权衡（帕累托）。
- **硬约束 Hard constraint** — 必须满足、不可违反的约束（像线性规划里的约束，不是惩罚项）。本项目工艺安全 = 硬约束，且强制在模型之外。
- **概念漂移 Concept drift** — 数据生成分布随时间变化（炉子改造后 x→y 关系变了），违反"训练 / 测试同分布"假设，模型失准，需重训。
- **影子运行 Shadow deployment** — 新模型先并行跑、不真正下发参数，用来和现行方案对比。类比：生产环境里的 holdout / 交叉验证式评估。
- **评测靶子 Evaluation harness** — 把指标（应力斑判级）+ 约束（安全）做成自动化测试集，作为"模型行不行"的客观尺子。没有它，任何自动优化都是空转。
