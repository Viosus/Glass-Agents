# 工厂考察核对清单——ERP 前 AI 辅助录入系统

_订单流现状调研 · 2026-08_

> 用法：★ = 必问（答案直接决定可行性/方案形态）；△ = 补充（时间紧可跳）。每题下方灰字是「这题的答案决定什么」，追问时照着它挖；「记：」行现场手写。问题按访谈对象分组，同一人一次问完；末尾另有【现场实验】【带回实物】两张清单，离厂前逐项打勾。

## 〇、行前准备

- [ ] **P1** 行前电话向老板确认：样本能否带走（A8 口径）、能否安排半天蹲点跟单（S1）、审单师傅 1 小时单独访谈（G9）能否排开。
- [ ] **P2** 装备：笔记本电脑（当场开客户 Excel/PDF 验证）、U 盘、手机充电宝、本清单打印件 + 备用笔。
- [ ] **P3** 预备一份简单的保密承诺书（若厂方对带样本有顾虑，当场可签）。
- [ ] **P4** 访谈顺序建议：老板（定口径）→ 蹲点跟单 → 审单/内勤半天 → 生产车间 → ERP/IT → 财务/售后 → 运营部收尾；口径类问题（错单责任、源头改造）老板与一线分开问后对照。

## A、老板 / 管理层（建议单独约 30–60 分钟）

_拍板类问题只认老板本人的口径，不要只听中层转述。_

**A1 ★ 这套系统你们期望达到什么效果——不用人看直接出正式订单，还是接受「AI 打草稿、人最后确认」？如果手写单以后仍需人逐张过目，算成功还是失败？**
　　定：手写识别已证不可免复核；若预期是全自动，先做预期管理、重签验收标准，否则验收即翻车。　问：老板本人
　　记：

**A2 ★ 一次性建设预算大概什么量级（几万 / 十几万 / 几十万）？之后每年愿意为维护、规则更新、外部支持付多少？**
　　定：年维护预算为零则防劣化机制必烂尾；决定方案裁剪档位（全量 / 零模型版 / 不做）。　问：老板
　　记：

**A3 ★ 外部工程支持能接受什么形态：季度上门体检 + 需要时远程发新版本的年度合同行不行？紧急问题能接受多长响应（当天 / 三天 / 一周）？**
　　定：模型层留在工程侧的前提是这条支持通道存在；决定 SLA 与报价。　问：老板 + IT
　　记：

**A4 ★ 客户名单、成交价格算不算商业机密？外部工程人员能不能看真实订单？客户名换编号、价格抹掉之后能否带出厂？价格字段要不要对部分岗位隐藏？**
　　定：决定脱敏方案、保密协议条款、字段级权限设计，以及能否用真实历史单建测试集。　问：老板（唯一有权拍板的人）
　　记：

**A5 ★ 现在录错一张单谁担责、怎么赔怎么考核？以后 AI 预填错了、复核人没看出来，责任怎么算——能接受「最终确认人负全责」吗？**
　　定：责任谈不拢，一线会用「反正不是我填的」心态消极复核，系统反而放大错误。　问：老板当面表态；一线分开印证
　　记：

**A6 ★ 如果公司统一发预印分格的订单本，销售端压得动吗？以前推过类似规范没有、为什么没成？**
　　定：源头改造收益大于换模型，但它是纯组织问题；销售处另听真话（见 B12）。　问：老板（听决心）
　　记：

**A7 ★ 厂里以前上过哪些信息化系统（ERP、进销存、考勤、报工）？哪个还在用、哪个废了？废掉的怎么死的——没人维护、员工抵触、供应商跑路、还是不好用？**
　　定：上一个系统的死因大概率就是这个系统的死因；决定推广策略与要规避的失败模式。　问：老板 + 用过旧系统的老员工（分开问）
　　记：

**A8 ★ 考察当天能不能带走（或拍照带走）50–100 张手写单和 20 份客户 Excel/PDF？谁有权批？敏感字段现场遮盖还是回去统一脱敏？**
　　定：行前先电话确认一次，否则现场必卡壳、整个评估周期后移。　问：老板（行前电话 + 现场落实）
　　记：

**A9 △ 正式订单要不要回传客户签字/确认才算数？现在有这一步吗，客户配合吗？**
　　定：有回签 = 多一道天然纠错网，决定整体自动化的激进程度。　问：老板 / 销售主管
　　记：

## B、销售端（1–2 名销售 + 主管；要看手机、看实物、看演示）

_这一场重点不是问，是「翻」：翻单子、翻手机、看他现场拍一张单。_

**B1 ★ 最近一个月的订单按来源分：手写单拍照、客户 Excel、PDF、微信文字、电话口头，各占几成？——现场翻上个月的单子数一数，别只听估计。**
　　定：各渠道占比决定解析管线投入排序、手写识别值不值得做、复核人力预算。　问：销售主管 + 审单员（两边对口径）
　　记：

**B2 ★ 平常一天多少张订单？旺季峰值一天多少？最忙的时候会不会出现「来不及审、先下单后补审」？**
　　定：峰值下纪律是否被突破，决定确认环节做硬卡点还是软提示、以及峰值降级策略。　问：销售主管 + 生产调度
　　记：

**B3 ★ 手写单是谁写的——销售自己、客户、还是柜台代写？拿 10 张最近的原件看：字迹最好和最差的各什么样？**
　　定：写单人决定源头改造的施力对象；字迹分布决定识别预填的真实命中率。　问：销售员本人 + 审单员
　　记：

**B4 ★ 手写单有没有固定单式（公司统一格式 / 客户自带本子 / 白纸随手写）？有单式的占比多少？**
　　定：有分格单式可做版面锚定解析，正确率跳一个档；决定预印表格是从零推还是升级现有单式。　问：销售员 + 销售主管
　　记：

**B5 ★ 请销售现场演示一次「拍手写单发出去」：用什么设备、什么环境、什么角度？再翻 10 张最近微信里传的实拍看清晰度。**
　　定：识别效果一半死在拍照质量；拍照引导/翻拍台这类低成本改造比换模型便宜。　问：销售员本人（演示）
　　记：

**B6 ★ 微信订单长什么样（看手机）：打字清单、手写单照片、Excel 截图、语音各占多少？发到个人微信还是企业微信？出过「客户说改了尺寸但只在微信说了」的纠纷吗，怎么对证的？**
　　定：个人微信消息无法系统化导出，是数据链路最难自动化的一环；决定微信通道形态与证据留存设计。　问：销售员 + 销售主管
　　记：

**B7 ★ 改单/撤单的比例多高、一般改什么？微信里改来改去最后以哪条为准？单子已流转到生产才改的怎么处理？改过的单要不要重新审？生产怎么保证拿到最新版？**
　　定：决定订单版本化 + 重审触发机制是否一期必做；口头改单是数据一致性最大的洞。　问：销售 + 审单员 + 生产调度
　　记：

**B8 △ 电话/口头订单占多少？接完电话怎么落到纸面——随手记、事后补单、还是口头报内勤？**
　　定：口头单没有原始凭证，是错单和扯皮高发源；决定要不要做快速登记入口。　问：销售员 + 内勤
　　记：

**B9 ★ 发 Excel/PDF 的客户多少家有固定模板？一共多少种格式、新格式一个月冒几次？现场拷 20 个最近真实文件（可先抹价格）。顺带问：厂里用微软 Office 还是 WPS？老 .xls 格式多不多？**
　　定：解析器开发量与格式种数成正比；模板月增频率决定运营部能否自维护模板库；WPS/老格式兼容要提前摸底。　问：销售内勤（收文件的人）
　　记：

**B10 ★ 客户发的 PDF 是导出的文本型，还是扫描/拍照转的？——当场打开几个最近的 PDF，试试能不能选中文字。**
　　定：文本型 PDF 零模型确定性解析；扫描型实质是图片得走识别+复核，可行性结论完全不同。　问：审单员（当场开文件验证）
　　记：

**B11 ★ 经常下单的客户多少家？前 5 大客户占总单量几成？各是什么类型（工程公司/门窗厂/装饰公司/散客）、习惯用什么方式下单？**
　　定：客户集中度高 → 给几家大客户发模板即可覆盖大半单量；长尾散客为主才是手写识别的主战场。　问：销售主管（拿单量排名数据）
　　记：

**B12 ★ 预印分格订单本，你们（销售）自己愿不愿用？嫌麻烦在哪？客户手写的部分能不能也换成我们给的格式？**
　　定：与 A6 老板口径对照：老板有决心 + 销售不抵触，源头改造才成立；否则手写识别预期整体调低。　问：销售员（单独问，听真话）
　　记：

**B13 △ 同一张订单客户会不会多渠道重复发（微信一遍、电话一遍、再补 Excel）？现在靠什么避免录成两单？**
　　定：决定要不要做跨渠道订单去重/合并逻辑。　问：内勤 / 审单员
　　记：

**B14 △ 销售团队几个人、流动性如何？平时主要用手机还是电脑？打字和用 App 的熟练度什么水平？**
　　定：决定录入前端形态（手机拍照 vs 桌面上传）与培训成本。　问：销售主管
　　记：

## C、审单 / 内勤（核心场，建议预留半天；含两个现场实验）

_字段、写法、规则的「真值」全在这一场；口径类问题要两个人分开问。_

**C1 ★ 拿一张最近的真实订单，逐项过订单头字段：客户名、工程名、下单日期、交期、联系人、送货地址、结算方式、销售员……全集是哪些？哪些必填、哪些经常空着也照样往下走？**
　　定：统一格式的字段模型与必填校验清单，全部以此为真值。　问：审单员 + 销售（对照口径）
　　记：

**C2 ★ 一行玻璃明细最多有多少字段（宽、高、厚、数量、品种、工艺、单价、金额、备注…）？翻出厂里字段最多、最复杂的一张单看看。**
　　定：明细行是解析和审核的主战场，字段上限决定数据结构天花板。　问：审单员
　　记：

**C3 ★ 同一片玻璃要钢化+磨边+打孔，是写一行多工艺还是拆多行？有没有规矩？两个销售写法一样吗？**
　　定：决定工艺是行属性还是子表结构；写法不统一则解析要做归并。　问：销售 + 审单员
　　记：

**C4 ★ 中空/夹胶的规格写法现场抄几个真实例子：6+12A+6、6+1.14PVB+6、5厚+9空+5厚……同一含义有几种变体？大小写、中英文、间隔符乱不乱？**
　　定：这是解析最难的文法，变体清单直接决定归一化词典的工作量。　问：审单员（现场翻单子抄录）
　　记：

**C5 ★ 尺寸单位 mm/cm/米混用多不多？有没有「不写单位默认 mm」的潜规则？不同客户默认一样吗？有没有因单位错做错货的先例？**
　　定：单位歧义是数值归一化头号陷阱，默认规则必须来自现场而非假设。　问：审单员 + 销售
　　记：

**C6 △ 写 1200×600 时宽高顺序有约定吗？对磨边方向、孔位有影响吗？写反了算谁的错？**
　　定：决定归一化能否自动交换宽高、方向性字段要不要单独审。　问：生产师傅 + 审单员
　　记：

**C7 △ 数量单位有没有「片/套/樘/平方」混用？「一套」等于几片谁定义？按平方下单怎么换算成片数？**
　　定：数量单位歧义会让数量×面积的算术校验整体失效。　问：销售 + 审单员
　　记：

**C8 ★ 过去一年出现过的「特殊要求」列个清单：丝印、Low-E 膜面朝向、包装、圆角、倒棱、孔位按图……哪些高频、哪些一年一遇？现在分别记在哪——备注栏、微信、还是口头交代？**
　　定：特殊要求是正式订单的核心增值项，类型分布决定备注的结构化程度与词典初始规模。　问：销售 + 生产调度（两头对传递链）
　　记：

**C9 △ 带图纸的异形单占比多少？图纸以什么形式来——CAD（DWG/DXF）、PDF 图、手绘、拍照？谁把图纸翻译成加工尺寸？图和表不一致时以哪个为准、出过事吗？**
　　定：客户给电子图则尺寸可机读、异形单可部分自动化；全是手绘照片则必须人工旁路。　问：审单员 + 接图最多的销售 + 下料师傅
　　记：

**C10 ★ 现在审单的是谁、什么背景？平均一张审多久、一天多少单？旺季堆单时最先崩的是哪个环节？**
　　定：审核耗时与瓶颈位置 = 自动化收益测算的硬数字。　问：审单员本人 + 主管（数字互相印证）
　　记：

**C11 ★ 最近一个月被审核拦下来的问题逐条翻记录或回忆：尺寸超限、厚度写错、算术错、漏填、工艺冲突、单价不对……各占几成？有没有留底可以数？**
　　定：拦截类型分布 = 校验规则开发的优先级排序依据；纯规则能覆盖几成决定自动审核的成色。　问：审单员
　　记：

**C12 ★ 面积和金额到底怎么算：不足 0.5㎡ 按 0.5㎡ 计这类进位规则有吗？金额除了面积×单价×数量还有哪些加价项——打孔按孔、磨边按延米、异形加价、加急费？拿价目表或计价规则当场看。**
　　定：算术审核要全自动，计价公式每个分支都必须成文；一个隐藏加价项就能让自动核算全错。　问：开单员 / 销售内勤（拿价目表实物）
　　记：

**C13 ★ 面积、金额的舍入规则：保留几位、四舍五入还是一律进位？不同客户合同口径一样吗？审核时金额差多少以内不算错？**
　　定：舍入与容差是判错阈值，口径不一会导致自动审核大量误报。　问：财务 + 销售内勤
　　记：

**C14 △ 单价从哪来：统一价目表、客户年度合同价、还是销售现谈现填？折扣谁批、记录在哪？审单核不核价格？**
　　定：决定价格字段是可校验项（有真值来源）还是只能人工确认项。　问：销售主管 + 财务
　　记：

**C15 ★ 凭经验，哪三个字段最常漏填（交期、厚度、膜面、磨边、单价…）？漏了一般拖到哪个环节才被发现，返工代价是什么？**
　　定：缺漏检查按「发生率×代价」加权分级：高发高代价字段设硬拦。　问：审单员 + 生产调度
　　记：

**C16 ★ 有没有任何成文的审单清单、工艺限制表、禁做清单？有就借来拍照；没有的话，上一个老审单员离职时是怎么交接的？**
　　定：规则成文度决定规则库建设是「抄写工程」还是「知识抢救工程」，工作量差一个量级。　问：审单员 + 主管
　　记：

**C17 ★ 【实验】同一张有歧义的单分别给两位审单师傅判（勿同场）：判断一致吗？出过「张师傅放行、李师傅拦下」吗？分歧谁说了算？**
　　定：口径不一致 = 不存在唯一真值规则，该类判断只能做「提示+人裁决」而非自动判定。　问：两位以上审单员（分开问）
　　记：

**C18 ★ 客户名称、玻璃品种（白玻/超白/Low-E 各型号）在单据上的写法有多少变体——简称、俗称、错别字？客户主数据和品种主数据在哪（ERP、Excel、脑子里）？**
　　定：归一化词典是开放给运营部维护的核心数据资产，主数据现状决定词典冷启动成本。　问：销售内勤 + IT（若有主数据）
　　记：

**C19 ★ 历史订单存档（一次问全）：手写原件/照片、Excel、最终确认版各存了多少、几年、在哪？能不能批量拿到？被拦下的错误原单有没有「原单+改后」对照留底？**
　　定：历史订单 = 规则提炼素材 + 冻结测试集的唯一原料；错单对照样本是检验规则召回率的金标准。配对实验见 S2。　问：内勤 + 档案管理 + ERP 管理员（只走一遍档案室）
　　记：

**C20 ★ 现在出给客户和车间的「正式订单」长什么样：固定版式？要不要盖章/签字才生效？单号怎么编？有没有工程客户指定必须用他们的格式回签？**
　　定：正式订单就是本系统的最终交付物，版式/签章/编号/回签格式决定输出模板的套数。　问：销售内勤 + 审单员（拿实物对照）
　　记：

**C21 △ 审核除了内容正确，还把哪些关：交期排不排得下（产能）？客户欠款要不要先收款？特殊原片（超白、Low-E 型号）有没有货？这些现在谁说放行才算数？**
　　定：隐性闸口若在现状审核内，系统边界必须明确「含」或「切」；边界含糊比不做更伤信任。　问：审单员 + 财务 + 采购 + 生产调度
　　记：

## D、生产 / 车间（跟单走一圈 + 翻记录本）

_这一场的重点是实物和台账：生产单、补片记录、废品统计，比任何人的回忆都可靠。_

**D1 ★ 车间师傅实际拿到的生产单/流转卡长什么样——审核通过的订单直接打印，还是调度重新抄一份、或排版软件另出一张？现场跟一张单从审核走到切割工位，把中间每张纸都拍下来。**
　　定：若到车间还要人工转抄，转抄错误是本系统管不到的，收益边界要划清；生产单字段才是统一格式的真正下游需求。　问：生产调度 + 切割工位师傅（跟单）
　　记：

**D2 ★ 切割/下料用不用排版优化软件？它吃什么输入——手工逐条敲、Excel 导入、还是 DXF？谁录的？当场演示录一张单并计时。**
　　定：排版软件是订单数据的第二个重录点；若有导入格式，统一格式可直接多输出一路，复用价值翻倍。　问：下料/排版操作员（当场演示）
　　记：

**D3 ★ 生产中发现尺寸不对或玻璃炸了要补片：补片单怎么开、走不走审核？一个月补多少片，其中「订单本身写错」占几成？翻补片记录本。**
　　定：补片记录是错单率最客观的史料；还决定系统要不要支持补片单这种单据类型。　问：车间班组长（翻记录本实物）
　　记：

**D4 ★ 因订单信息错误做废的玻璃怎么处理？一片典型规格废片的全成本（原片+工时+延误）大概多少？月度废品统计里「订单/信息错误」类占比多少？**
　　定：项目收益的分子应靠统计不靠「最贵一单」的轶事；也决定验收指标「订单错误废品率」是否可测。　问：生产主管 + 质检/统计员（拿统计表）
　　记：

**D5 ★ 逐条产线问最小/最大加工尺寸：钢化炉、夹胶线、中空线、磨边机、钻孔机各多少？这些数字写在哪——设备铭牌、工艺文件，还是师傅脑子里？逐条抄录并拍出处。**
　　定：尺寸超限是审核第一大类硬规则，限值必须有出处；无成文的现场抄录、注明来源人。　问：生产师傅 / 工艺员（逐产线）
　　记：

**D6 ★ 实际生产的原片厚度有哪几档？接过枚举之外的厚度吗？中空、夹胶的合法厚度组合有没有明确的表？**
　　定：厚度是封闭枚举还是开放集，决定校验做白名单硬拦还是仅提示。　问：工艺员 + 采购（库存反映真实档位）
　　记：

**D7 ★ 哪些工艺组合不允许或必须成对出现？打孔是否必须先于钢化？半钢化能不能夹胶？磨边类型与厚度有没有绑定？逐条说全。**
　　定：工艺互斥表是纯规则可全自动拦截的高价值项，必须由懂工艺的人一次给全。　问：生产/工艺主管
　　记：

**D8 ★ 错单一般在哪个环节被发现——审核、排产、切割/钢化、还是到客户手里？各环节大概各拦多少？**
　　定：发现点越靠后成本越高；决定复核点设在哪、上线后用「错误发现前移」当效果指标。　问：审单员 + 班组长 + 售后
　　记：

**D9 △ 加急单怎么走？谁有权定加急、怎么标记、审核会不会被跳过？**
　　定：加急单最易绕过流程直插生产；决定要不要做「加急快速通道」（简化但不跳过关键校验）。　问：销售主管 + 生产调度
　　记：

## E、ERP 与 IT（要当场操作验证，不要只听说）

_「能导出」「能导入」必须当场演示一遍才算数。_

**E1 ★ ERP 什么品牌、什么版本？标准版还是定制过？装在厂内服务器还是云端/供应商托管？**
　　定：品牌与部署形态决定一切对接手段的可能性边界；定制过的系统往往文档缺失。　问：IT / ERP 管理员（无专职 IT 就找当年实施对接人）
　　记：

**E2 ★ 订单能不能不手敲进 ERP？三条路逐一问：① 有没有官方 API？② 有没有「Excel 批量导入订单」功能——当场演示一次；③ 能不能直连数据库或写中间表，供应商允许吗？**
　　定：最后一公里：三条路都不通，AI 产出仍要人工重录，系统价值砍半。　问：IT + ERP 供应商（最好当场电话问）
　　记：

**E3 ★ 请录单员当场录一张真实订单进 ERP 并计时：一共多少字段？哪些必填？哪些下拉选、哪些手敲？平均一单几分钟、一天录多少单？**
　　定：收益测算基线 + AI 预填字段的优先级排序（先做占时最长、出错最多的字段）。　问：录单员本人（不是主管）
　　记：

**E4 ★ ERP 里产品/工艺/客户这些下拉字典谁维护？多久加一次新条目、走什么流程？能不能完整导出一份？**
　　定：自由文本→ERP 字典映射是转换的落点；字典能否导出、由谁管，决定词典数据面能否交给运营部。　问：ERP 管理员 + 审单员
　　记：

**E5 ★ 【实验】现场从 ERP 导出最近三个月订单明细（Excel/CSV）：要不要老板审批？导出表里含不含客户名和价格？**
　　定：验证「可导出」是实际可操作而非口头说说；暴露审批门槛与敏感字段范围。　问：ERP 管理员（当场操作）+ 老板（审批口径）
　　记：

**E6 ★ 订单在 ERP 里有哪些状态（草稿/待审/已审/下达生产）？审核是在 ERP 里点，还是 Excel 看完再录？AI 预填的订单应落在哪个状态、由谁审？**
　　定：AI 产出必须嵌进现有审批链而不是绕开它；确认动作要落在明确的状态节点。　问：审单员 + 销售主管
　　记：

**E7 △ 将来若系统自动写 ERP，用谁的账号？操作日志能查到「哪单谁录的」吗？现在是按录入人追责的吗？**
　　定：自动写入会打破「谁录谁负责」的责任链；决定机器人账号 vs 复核人账号方案。　问：老板 + ERP 管理员
　　记：

**E8 ★ 办公室和车间电脑能不能上外网？有没有「生产数据不出厂/不上云」的硬要求？若纯内网，各机器互通吗、有没有共享盘或内网服务器？**
　　定：「离线」的严格程度（可临时联网装环境 vs 物理隔离）决定部署与更新分发方式、远程支持是否可行。　问：IT + 老板（保密由老板拍板）
　　记：

**E9 ★ 现有电脑/服务器盘点（带我现场看、拍配置页）：CPU、内存、有无独显、系统版本？有没有 XP/Win7 老机器在跑关键软件？有闲置或采购计划吗？**
　　定：决定本地模型选型的算力预算、方案里要不要列硬件采购项及金额。　问：IT（现场看机器）
　　记：

**E10 ★ 厂里 IT 几个人、平时做什么（修电脑/管账号/会不会脚本或 SQL）？ERP 出问题自己修还是全靠供应商？这几年换过几茬？一周能给新系统留几小时？**
　　定：IT 水位决定运维分工：哪些故障本地能接、哪些必须买外部支持，交接文档写到什么深度。　问：IT 本人 + 老板（问稳定性）
　　记：

**E11 △ ERP 现在谁在备份？多久一次、备到哪？真用备份恢复过吗？**
　　定：新系统的词典/规则/测试集同样要备份；现状备份纪律预示新系统数据资产的存活率。　问：IT / ERP 管理员
　　记：

**E12 △ 停电或断网时销售怎么接单、生产怎么开工？ERP 宕过一两天吗，当时怎么顶的？**
　　定：AI 录入若成必经环节，它宕机就是新单点；现状降级手段决定系统的旁路设计（能否随时退回纯人工）。　问：销售主管 + 生产调度
　　记：

**E13 △ 除了 ERP，还有哪些系统在用订单数据——排产、切割排版、财务软件？订单数据怎么进去的（自动传/人工再录）？**
　　定：若订单要二次三次重录，结构化产出的复用价值更大；统一格式字段范围别定窄了返工。　问：生产调度 + 财务 + IT
　　记：

**E14 ★ ERP 供应商还正常服务吗？年维护费多少？请他们开一个导入接口或做对接，报价什么量级、周期多久？以前做过二次开发吗？**
　　定：供应商失联或报价过高会直接改变方案取舍（官方开发 / 自研旁路 / 放弃写入只出导入文件）。　问：老板（付钱人）+ IT（联系人）
　　记：

**E15 △ ERP 多久升级一次、谁做？上次升级后出现过报表/导入模板变了的情况吗？**
　　定：升级会动接口/模板，则对接层要做版本适配并纳入回归监控。　问：IT / ERP 管理员
　　记：

## F、财务 / 售后（翻台账）

_两本台账（对账纠纷、客户投诉）是按真实代价加权的错单史料。_

**F1 ★ 订单前面有没有报价单/合同环节？工程客户是不是先签总合同再分批下单？订单的价格数量要不要和合同核对——谁核、拿什么核？分批下单的累计数量有人盯吗？**
　　定：若订单是合同的子单据，审核要加「订单↔合同一致性」校验，合同也是价格真值来源；分批还有累计超量风险。　问：销售主管 + 财务
　　记：

**F2 △ 月底对账开票时，因订单信息（数量/单价/规格）和送货对不上而扯皮的情况一个月几次？扯皮时怎么对证——要翻原始手写单吗？**
　　定：决定系统要不要保存「原始件↔结构化结果」的可追溯链接及存储期限。　问：财务 + 销售内勤
　　记：

**F3 ★ 客户投诉/退货有没有台账？翻最近一年的，当场数一数其中多少起根因是「订单录错/传错」而不是加工质量问题。**
　　定：按真实代价加权的错单史料，比回忆可靠；直接给出规则库先杀哪类错的证据，也可做验收指标。　问：售后/质检负责人（拿台账实物翻）
　　记：

## G、运营部与「迭代交接」（决定后续谁来养这套系统）

_「迭代交给运营部」是否成立，答案全在这一场；技能类问题必须看实操，不能只口头问。_

**G1 ★ 运营部一共几个人？各自管什么（谁录单、谁审单、谁对接生产）？录审是专职还是兼职？**
　　定：复核环节和后续迭代都压在这几个人身上，编制决定能否常态化运转。　问：运营部主管
　　记：

**G2 ★ 【实操】请每位成员现场演示日常 Excel 操作：会不会 VLOOKUP/筛选/数据有效性？有没有人改过任何软件的「设置/参数/模板」（打印模板、群机器人、考勤规则都算）？**
　　定：「迭代交运营部」的前提是至少一人有配置类工具的操作直觉；口头问不可信。决定配置界面开放到什么颗粒度。　问：运营部每位成员（逐个演示）
　　记：

**G3 ★ 运营部近三年走了几个人？新人平均多久上手？最资深和最新的人各干了多久？**
　　定：配置管理员一年一换则词典规则必失控；流动率决定权限绑岗位还是绑人、防呆做多重。　问：主管 + 老板（口径互相印证）
　　记：

**G4 ★ 如果指定一名「配置管理员」（细心 + Excel 熟练，负责改词典/规则参数并留记录），心里有人选吗？这个人愿意多担这份活吗、要不要加钱？**
　　定：治理方案需要具名责任人；无人选则数据面也得收回工程侧，成本结构大变。　问：主管（再单独问候选人本人意愿）
　　记：

**G5 ★ 运营/内勤现在的考核指标是什么——按出单量/速度，还是有准确率指标？出错单扣多少、晚出单扣多少？**
　　定：KPI 只奖速度不罚错误，复核环节会被跳过或糊弄；决定要不要同步改 KPI、界面做防跳过设计。　问：运营主管 + HR/管事副总
　　记：

**G6 ★ 改一条审核规则（比如某厚度的尺寸限值），现在谁点头才能改？以后系统里改规则，「一人修改 + 另一人确认 + 自动留痕」的双人制能接受吗、嫌不嫌麻烦？**
　　定：变更留痕和双人复核是防劣化核心纪律，小厂常嫌重；接受度当面试探。　问：运营主管 + 老板
　　记：

**G7 △ 上线后需要有人每周抽 5–10 张单对照原始件核查系统输出，这活谁干、每周拿得出几小时？质检口有没有现成抽检习惯可以搭车？**
　　定：抽检是防规则漂移的最后防线，必须有具名的人和固定时间，否则形同虚设。　问：运营主管 + 质检负责人
　　记：

**G8 △ 如果配置管理员离职，他改过的词典/规则/模板，接手的人看得懂吗？现在任何岗位有交接文档的习惯吗？**
　　定：无交接文化则系统必须强制「每次修改必填原因备注」并自动生成规则台账。　问：运营部主管
　　记：

**G9 ★ 【专场】审单老师傅单独访谈（≥1 小时，别当着老板）：先做「出声审单」实验（见 S3），再请他举三个「一眼就知道有问题」的例子；问他愿不愿把经验写成规则、当规则的「裁判」（误报漏报他说了算）；担不担心被替代？**
　　定：规则库冷启动的第一批条目从这里来；知识提供者若有替代焦虑会藏关键经验，「裁判」地位是常见化解方式。　问：审单老师傅本人（单独、录音须征得同意）
　　记：

**G10 △ 如果先小范围试点，选哪个切入——某一位销售的全部订单，还是只接 Excel 的客户？试点期间新旧流程要不要并行双跑？双跑结果谁比对、记在哪？**
　　定：双跑比对是不担生产风险前提下量化准确率的唯一办法，也是验收数字的唯一可信来源。　问：老板 + 运营部主管
　　记：

## S、现场实验与演示（离厂前逐项打勾）

_这些是要「做」的，不是问的；每一项都比对应的访谈答案更可信。_

- [ ] **S1 ★** 蹲点跟单半天：从销售接到一张真实新订单起，全程跟到录入→审核→下生产，只看不打断，事后补访谈。
　　问出来的是「应然」，蹲出来的才是「实然」——跳步、口头传话、先干后补只有蹲点能看见。
- [ ] **S2 ★** 配对实验：随机抽一张三个月前的手写单，看能否在 10 分钟内找到它对应的 ERP 记录。
　　「原始件↔正确结果」配得上是建测试集的硬前提；三路都问了存档在哪，只有这个实验能验证配不配得上。
- [ ] **S3 ★** 出声审单：给审单员一张干净单 + 一张有问题的真实单，请他边审边说在看什么、和什么比对、什么情况会停下（记笔记/征得同意录音）。
　　出声思维比回顾式提问挖隐性规则更全更真——人复述自己的判断依据时会系统性遗漏真正用到的线索。
- [ ] **S4 ★** 双师傅口径实验：同一张有歧义的单分别给两位审单师傅判（勿同场），比对结论。
　　对应 C17。
- [ ] **S5 ★** ERP 录单计时：录单员当场录一张真实订单，记字段数与耗时。
　　对应 E3。
- [ ] **S6 ★** ERP 导出演示：当场导出最近三个月订单明细。
　　对应 E5。
- [ ] **S7 ★** PDF 文本型验证：打开几个最近的客户 PDF，试选中文字。
　　对应 B10。
- [ ] **S8 ★** 拍单演示：销售现场演示平时怎么拍手写单、怎么发。
　　对应 B5。
- [ ] **S9 ★** 排版软件录入演示：下料员当场把一张单录进排版软件并计时。
　　对应 D2。
- [ ] **S10 ★** 链路计时表：沿「销售→内勤→审单→ERP 录入→下生产」各岗位，把每一手的耗时一次采完，现场画流转链路草图并请各岗位确认。
