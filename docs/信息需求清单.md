## 使用方式
1. 拿到任何一项 → 按"去向"列填入对应文件（config 改完即时生效，无需重启）。
2. 涉及安全限值（板块 A）→ 填完跑 `pytest tests/` 确认闸门行为变化符合预期。
3. 新炉上线 → 板块 B 全套走一遍 + `config/furnaces.yaml` 加条目 + 分配 furnace_id。
